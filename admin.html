Referral codes

Every enrolled doctor has one personal code they can share again and again. A doctor who joins with it gets 25% off, the lowest price we offer (it never goes below the Rs 2,999 founding fee). The referrer gets nothing. A referral code cannot be combined with a promo code. Doctors can find their own code at /refer.
