# caspianobesity-site

Source for **caspianobesity.com** — the CASPIAN Certificate in Obesity Medicine course site (Caspian Healthcare Foundation).

Static site + Vercel serverless functions (`/api`) for Razorpay Standard Checkout. Auto-deploys to the `caspianobesity` Vercel project on push to `main`. Set `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` in Vercel env vars (never commit them).
